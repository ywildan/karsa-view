# karsa-view

Dokumentasi fitur & preview layar SiKarsa Compose — aplikasi Android native Jetpack Compose untuk pencatatan poin keaktifan mahasiswa UNTIDAR, grup kelas, absensi, dan perpustakaan Karsa Lib.

Situs ini adalah viewer statis (Vite + React 19 + Tailwind CSS 4, build single-file). Bukan aplikasi utamanya — kode Android aslinya ada di `ywildan/karsa` (`karsa-mobile-compose`).

Deploy: Vercel, domain `view.sikarsa.id`.

## Jalankan lokal

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output di `dist/` (single HTML).
